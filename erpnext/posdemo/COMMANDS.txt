TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────

Problem: "Site not found"
Solution: List sites: bench --site
          Use exact site name from sites/ folder

Problem: "Permission denied" on scripts
Solution: chmod +x run_import.sh
          chmod +x validate_csv_files.py

Problem: "Module not found"
Solution: Make sure you run from bench directory

Problem: Import too slow
Solution: Normal! 2,247 items take 5-15 minutes
          Check progress in output

Problem: Some records failed
Solution: Safe to re-run! Script skips existing records
          Check error messages for specific issues

TIPS & BEST PRACTICES
─────────────────────────────────────────────────────────────────────

✓ Always validate first (python3 validate_csv_files.py)
✓ Safe to re-run - skips existing records
✓ Can interrupt (Ctrl+C) and resume later
✓ Test on staging site first if available
✓ Check output for errors - they're detailed
✓ Expect 5-15 minutes for full import
